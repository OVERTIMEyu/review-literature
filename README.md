# 文献综述四阶段 · review-literature

用于 Codex 的文献综述技能：摘要矩阵筛选 → 严格证据链精读 → 主题联动与方法对比 → 综述写作。可从已有阶段继续，沿用项目目录、文献 ID、模板与有效成果。

## 主要能力

评述以研究成果为对象，关注实际结果、认识与能力、解决程度、价值及实质局限。方法与过程用于解释成果，不以过程挑错代替评述。

- R1：生成摘要矩阵、标签规范和精读建议，区分摘要未报告与全文缺失。
- R2：形成可追溯的全文笔记，区分作者事实、模型分析和用户观点。
- R3：比较方法与工况，分析研究间的关系，判断已有成果解决了什么、解决程度及具体瓶颈。
- WRITE：按问题组织综述，评价实际效果、适用性及相关工程与商业价值，核对引文和证据。
- 状态管理：保存成果后更新状态与日志；材料不足、核验未完成、信息冲突和来源变化均有明确标记。

## 安装

从 [Releases](https://github.com/OVERTIMEyu/review-literature/releases/latest) 下载 `review-literature-v1.0.1.zip`，解压后将 `review-literature` 文件夹放入 Codex 技能目录（通常为 `~/.codex/skills/`）。目录中应直接包含 `SKILL.md` 与 `references/`。重新打开 Codex 后使用。

也可克隆本仓库至技能目录下的 `review-literature` 文件夹。

## 使用

在 Codex 中输入，例如：

> 使用 $review-literature，对本批文献完成一轮摘要筛选，沿用现有 ID 和标签规范。

> 使用 $review-literature，从已有精读笔记开展第三轮主题综合，给出当前研究成果的能力、取舍和具体瓶颈。

项目材料、状态和成果保存在项目目录，技能目录仅保存规则与写作参考。工具不可用或材料不足时，记录原因并交付可支持部分。

## 文件

- `SKILL.md`：四阶段的交付物、禁止事项、转段条件与异常标记。
- `references/写作规则-现状判断与综合评价-v1.md`：研究推进、实际效果与现状评价的详细规则。
- `references/写作示例-第三轮综合评述规划摘录-v1.md`：保留的完整主题写作示例。
- `references/写作示例-研究现状反例与改写-v1.md`：常见写法问题与适用条件。

写作示例用于说明论述方式。正式写作中的文献事实与数字须回查原文，不能把示例当作文献证据。
