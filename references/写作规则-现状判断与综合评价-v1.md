# 写作规则：明确评价已有研究与研究现状

适用于 R3 主题综合、研究现状撰写及综述正文修订。规则依据是用户在《ChatGPT-综述深化建议.md》中的纠正原话；写作示例参照用户指定的规划 v1；规划 v7 的改前—改后示例已按用户要求移除，优化后另行提供。

## 1. 核心要求：当前评价必须完成

### 用户原话

以下保留关键原话，去除编号和引用格式：

> 而且我们到最后应该给现有现状一个定论 而不是因而……不能……

> 研究的分析要具体分析他解决了哪方面的问题 注意这个解决也要探究更深层一点的而不是只听作者说

> 用什么方法解决也要写

> 不要光写研究价值啊，还有应用价值、商业价值等等等，可以说他这个结构可能不够结实、不够适用……，也可以说不适合商用，在我这个场景研究价值才是相对没那么重要的。

> 不一定非要有技术原因，如果觉得有可能不对的话就直接说可能加工困难等等，先按照可能的直接提出即可

> 每个研究不要用相同的篇幅和相近的句式长短，要错落有致。

> 我觉得写工程指导范围没啥必要的感觉，像硬凑

来源：所提供对话第425—426、803、805及1030行。下文将这些要求落实为分析和写作规则。

### 执行要求

综述应让读者知道：已有研究实际解决了什么、采用的方法怎样发挥作用、解决程度如何、各条路线的价值与代价是什么，以及这一方向目前发展到了哪一步。

核心写作问题是：有介绍、有保留话，却始终没有明确评价；把研究现状写成一连串“尚不能证明”“仍需考察”“未来应加强”，读者读完仍不知道现有成果到底表现怎样、具体哪里有效、哪里薄弱。

**R3 与 WRITE 必须完成当前可以作出的实质判断。禁止用未来研究建议代替现状评价，禁止用笼统的不确定性悬置已有证据支持的结论。**

判断应明确到研究对象、评价维度和成立条件，沿着具体方法、作用机制和实际结果分析问题，再说明这些表现对设计、使用或认识意味着什么。保留原文中已经准确的技术内容与判断落点，避免抽象概括削弱原意。判断范围可以是单篇成果、一组可比较研究或已覆盖的研究方向。

## 2. 单篇研究：解释实际推进与解决程度

把一项研究理解为对某个问题的一次具体推进。围绕重要性选择展开以下内容：

1. **问题与方法。** 作者试图解决什么，采用什么理论、结构、模型或试验；关键方法和设计选择怎样发挥作用。
2. **实际成果。** 取得什么结果，在什么条件下成立，具体改善了什么，局部收益怎样体现在整体表现中。
3. **深层贡献。** 从作用机制和工程实际分析，它突破了什么限制、解决了原问题的哪一部分、解决到什么程度，而非只复述作者自评。
4. **直接缺陷。** 结构、模型、试验、指标、数据或论证中存在什么具体问题，怎样影响性能或应用任务。
5. **隐藏缺陷。** 从基础常识、结构形态和使用过程主动提出可能的强度、磨损、堵塞、加工、维护、能耗、寿命和成本问题；不以作者是否提过为限。
6. **最终评价。** 对实际效果、技术水平、适用性、可靠性、实施代价及实际价值作出明确判断。工程装备综述应重视应用和商业竞争力，科研价值是其中一项。

据此形成对该成果的整体评价。机理研究重点解释其认识贡献，预测研究重点说明预测能力，设计与装备研究重点分析实际效果和工程得失。分析深度随成果的重要性安排，不要求每篇凑齐相同的层次、段数或句式。

评价围绕真正有关的技术和应用问题展开，不为每项成果硬凑“工程指导范围”，也不把制造、维护、使用经济性等具体问题缩成“研究价值”。基础或方法研究按其认识贡献、解释与预测能力及相关用途评价。

## 3. 同主题比较：从多项工作形成新的认识

每个主题先简短引入问题，分别评议代表性研究，再开展交叉比较，最后对现有技术下结论。先把具体工作讲清，再分析研究之间真实的关系。比较应回答：

- 不同路线怎样解决同一个问题，各自依靠什么机制或方法，主要优势和代价是什么。
- 相同或相近方法在不同条件下为什么表现不同，这些差异怎样改变对方法能力和适用场景的理解。
- 各项工作之间有哪些承接、互补、竞争、制约或分歧，哪些关系最能解释这一方向的进展。
- 单项性能改善怎样传递到整体效果，哪些代价会影响方案选择，什么问题需要跨主题理解。

联合评价应产生超出单篇介绍的认识。例如，指出某类方法擅长解释作用机制，另一类方法更适合实际参数筛选；或者说明某结构的性能收益与维护代价构成怎样的取舍。

解释差异、评价能力、比较价值是论述的主体。主动追问多项研究背后共同没有解决的具体问题，以及已有解决方案的实际效果。研究数量和文献归类按当前项目规划执行，不把某份规划的章节、文号或数量门槛自动套用于全部综述。

## 4. 主题与领域：给出有内容的现状判断

每个主要主题在完成分析后，应清楚交代：

- **已经建立的认识和能力。** 哪些问题已得到解释，哪些功能已实现，哪些成果在实际应用中发挥了作用。
- **主要路线的相对位置。** 不同路线分别解决什么，在哪些任务或条件下更有优势，采用它们需要付出什么代价。
- **目前的实现程度。** 从具体成果说明理论、方法、试验或应用发展到了哪一步，使“有效”“成熟”“适用”等评价有实际内容。
- **主要瓶颈及其影响。** 具体是哪项认识、预测、设计或实施能力受限，为什么成为重要限制，对下一步推进有什么影响。

章节或全篇综合评述再归纳跨主题认识，给出研究方向的整体评价。将局部改进放回整个问题中，解释已有进展改变了什么、剩下的核心问题是什么。

“研究已经较为充分”“这条路线在特定任务下有效”同样是重要判断。综述的立场来自分析结果。

## 5. 现状判断与后续问题的衔接

现状评价回答“现在怎样”；后续问题回答“接下来值得推进什么”。先完成前者，再由已经识别的重要限制引出后者。

以下情况必须继续完成论述：

- 写到“不能直接比较”时，应分析差异集中在哪些对象、条件或指标，以及这些研究分别建立了什么认识，仍有哪些维度能够形成有意义的比较。
- 写到“尚不能证明”时，应说明已建立的能力、具体未建立的能力，以及这一区别怎样影响当前评价。
- 写到“还需进一步研究”时，应先说清现状的具体短板及其实际影响，再按章节目的决定是否展开后续问题。

这些是对论述功能的要求，不是禁用词表。证据有限时，在相应层级明确已知能力和未知部分；证据已经支持明确判断时，直接表达该判断。

作者没有写出的问题，也可以独立提出。可以先写“可能加工困难”“局部薄壁可能不耐冲击”“沟槽可能滞泥”“维护成本可能偏高”等风险，再按重要性追查依据和反例；无需先有完整的强度、寿命或成本数据才允许提出合理怀疑。底稿区分原文结果、跨研究推断和专业常识推测；正文用“可能”“风险”等简短措辞表达推测，不编造实际失效或经济数据。

未来建议集中放在综合评述、研究计划或展望中。研究现状正文以理解、解释和评价已有工作为主，避免每段都收束成任务布置。题目已经确定时，深化与既定论题有关的现状判断，不另做选题清单，也不以个人暂时能做的变量代替整个研究方向的范围。

## 6. 写作参照：指定规划中的完整示例

动笔前读取[第三轮综合评述规划摘录](写作示例-第三轮综合评述规划摘录-v1.md)：

- 规划 v1 的完整小节展示怎样分别评议研究，再综合评价收益、代价和具体技术短板。

参照具体展开的深度和论述作用。各例按研究本身组织，不把它们压缩成“有一定价值，但尚不能证明”，不重新编造抽象的 A／B 方案替代原有工作。原话用于明确要求，规划示例用于说明写法，二者的用途分开。

## 7. 正文组织与完成要求

以问题和判断组织段落。先把理解所需的对象、结构或研究工作讲具体，再围绕真实关系开展比较、解释和评价。代表性研究可以详述，同一问题的系列研究可以合并为一个研究单元，按证据量用多段呈现基线、改进、验证及仍存问题。采用 v7 正文明确的“不设两段上限”口径，不沿用早期规划或简版注意事项的旧上限。篇幅、句长和顺序随内容与论证作用变化，不统一套用“提出—结果—但是—展望”。

目录可按研究对象、装备类型、技术路线或方法类别组织；正文在各类之内分析问题；综合评述归纳跨类认识。发展历程用于说明关键认识或能力怎样形成，工程价值用于解释实际取舍，两者都服务于文章主线。

R3 的主要主题和 WRITE 的综合评述完成时，读者应能回答：

1. 已有研究用什么方法解决了哪些问题，解决到了什么程度？
2. 主要路线各自能做什么，优势、代价和适用场景是什么？
3. 当前最重要的具体限制是什么，它怎样影响认识、方法或应用？

资料与范围已经支持上述判断，却仍以泛泛的保留话或未来建议结束，视为论述未完成。应补上分析和评价，而不是只替换几个连接词或加强语气。
